# PixelForge

Editor de pixel art y animación por capas. Versión actual: 1.5.

## Aplicación

https://pixelforge-domisur.vercel.app

## Despliegue continuo

La rama `main` de este repositorio está conectada al proyecto `pixelforge` del equipo DOMISUR en Vercel. Al enviar cambios a `main`, Vercel crea un nuevo despliegue de producción automáticamente.

El archivo principal de la aplicación es `index.html`.
